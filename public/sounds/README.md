# Event-Sounds

Lege hier lizenzierte Sounddateien fuer die Event-Zuordnung ab.

Unterstuetzte Dateinamen:

- t20.ogg
- t19.ogg
- t18.ogg
- t17.ogg
- bull.ogg
- dbull.ogg
- triple.ogg
- maximum.ogg
- checkout.ogg
- winner.ogg
- bust.ogg
- elimination.ogg
- cricket-score.ogg

Die Dateien werden ueber `/sounds/<dateiname>` ausgeliefert. Fehlt eine Datei, verwendet das Dashboard den bisher konfigurierten WebAudio-Fallback.
